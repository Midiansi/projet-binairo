## Cross-cutting safeguards

- Hardcoded personal absolute paths are prohibited by inherited R6 p41/A2 p7. Runtime absolute paths derived from the VI/script folder or a user selection are necessary and permitted by L1 pp10–11 and P26 p23. Quote them by the actual OS rules.
- Native MATLAB and LabVIEW remain **not executed by the agent**. Written code, source review, C execution and Python checks must be reported separately. A detailed recipe or a mocked diagram is not a working VI.
- Author names, software versions on the target computer, missing conversations, measurements, native outcomes and official answers must not be fabricated. Completed native evidence and professor answers will update this log.
- Course assets and personal transcript exports remain outside GitHub. The submission's separate restored assets and true available transcript PDFs must be included according to the eventual confirmed submission rules.
