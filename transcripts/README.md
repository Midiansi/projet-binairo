# Local-only conversation archive
Personal conversations are excluded from GitHub. `tools/export_transcripts.py` preserves visible user/assistant text from explicitly selected local logs in JSON, Markdown and optional PDF. It never exports hidden reasoning or system/developer messages. Do not treat task summaries as transcripts. Current-task snapshots end at a recorded UTC cutoff; refresh after the final reply and again after every repair. Previous project tasks located: `Plan optimal AI project strategy`, `PROJET`, `Implement Binairo project package`, and this task. Original pasted execution request is preserved separately locally. Attachments are referenced and backed up separately, never invented.

Missing teammate conversations are not available until teammates return exports. Keep each full conversation PDF, with real participant names supplied by the team, in this excluded folder. Do not edit out failed attempts. Use your chat app's actual Export/Print command if available; otherwise copy the full visible conversation into a local document and print to PDF, then compare beginning/end and attachment references. Exact app menus depend on the platform and are not claimed verified. Do not send personal chats or hidden reasoning to GitHub.

The delivery combines the four available conversation PDFs plus the separately preserved attached execution request into AI_PROJECT_TRANSCRIPTS.pdf. TRANSCRIPT_INDEX.json records each export timestamp, message count and page count. Per-conversation JSON and Markdown are retained without paraphrase. The active task's final reply and subsequent repair discussions cannot be in a snapshot created before those messages exist; refresh them at the next handoff. This is an explicit cutoff, not a fabricated claim of complete future history.
